Hardware Node Architecture

1. Combined Hardware: One ESP32-CAM module connected to an HLK-ZW101 optical sensor.

2. Dual Services: Video streaming runs on Port 81; fingerprint control, scan queries, and enrollments run on Port 80.

3. Templates Security: Fingerprint biometric templates remain securely stored inside the sensor's onboard flash memory.
